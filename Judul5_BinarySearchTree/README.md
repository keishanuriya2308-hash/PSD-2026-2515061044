Program Manajemen Data Nilai Mahasiswa Menggunakan Binary Search Tree (BST)
## b. Deskripsi Singkat
Program ini dibuat menggunakan bahasa Python dengan konsep struktur data Binary Search Tree (BST). Program digunakan untuk mengelola data nilai mahasiswa, seperti:
Menambahkan nilai mahasiswa, Menampilkan data nilai, Mencari nilai tertentu, Menghapus nilai mahasiswa.
Program menggunakan konsep BST sehingga data dapat tersimpan secara terurut dan proses pencarian menjadi lebih cepat.

## Penjelasan
Program Manajemen Data Nilai Mahasiswa Menggunakan Binary Search Tree (BST) merupakan program berbasis Python yang digunakan untuk mengelola data nilai mahasiswa dengan menerapkan konsep struktur data Binary Search Tree. Program ini memiliki beberapa fitur utama seperti menambahkan data nilai mahasiswa, menampilkan data menggunakan traversal inorder, preorder, dan postorder, mencari nilai tertentu, serta menghapus data nilai mahasiswa. Pada kode program terdapat class Node yang digunakan untuk membuat node BST yang memiliki data, child kiri, dan child kanan, serta class BST yang berisi method insert, traversal, search, dan delete. Method insert() digunakan untuk menambahkan data sesuai aturan BST, yaitu nilai lebih kecil ditempatkan di kiri dan nilai lebih besar di kanan. Method traversal digunakan untuk menampilkan data dengan urutan tertentu, di mana inorder menghasilkan data terurut dari kecil ke besar. Method search() digunakan untuk mencari data tertentu dalam BST, sedangkan delete() digunakan untuk menghapus node dari tree.
