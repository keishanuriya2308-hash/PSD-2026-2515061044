## a. Judul Program
Program Manajemen Data Nilai Mahasiswa Menggunakan Binary Search Tree (BST)
## b. Deskripsi Singkat
Program ini dibuat menggunakan bahasa Python dengan konsep struktur data Binary Search Tree (BST). Program digunakan untuk mengelola data nilai mahasiswa, seperti:
Menambahkan nilai mahasiswa, Menampilkan data nilai, Mencari nilai tertentu, Menghapus nilai mahasiswa.
Program menggunakan konsep BST sehingga data dapat tersimpan secara terurut dan proses pencarian menjadi lebih cepat.
