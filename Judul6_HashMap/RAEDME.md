## a. Judul Program
Sistem Data Mahasiswa Menggunakan Hash Map
## b. Deskripsi Singkat
Sistem Data Mahasiswa merupakan program sederhana yang dibuat menggunakan struktur data Hash Map. Program ini digunakan untuk menyimpan, mencari, menghapus, dan menampilkan data mahasiswa. Pada program ini, NPM digunakan sebagai key dan nama mahasiswa digunakan sebagai value. Penggunaan Hash Map memungkinkan proses pencarian data dilakukan dengan cepat dan efisien.

## Penjelasan
Ketika program dijalankan, pengguna akan melihat menu utama yang berisi beberapa pilihan operasi. Pengguna dapat memilih menu dengan memasukkan angka sesuai kebutuhan.
Jika pengguna memilih menu Tambah Data, program akan meminta input NPM dan nama mahasiswa, kemudian menyimpan data tersebut ke dalam Hash Map. Setelah berhasil, akan muncul pesan "Data berhasil ditambahkan!".
Jika pengguna memilih menu Cari Data, program akan meminta NPM yang ingin dicari. Jika data ditemukan, program akan menampilkan NPM dan nama mahasiswa yang sesuai. Jika tidak ditemukan, program akan menampilkan pesan "Data tidak ditemukan!".
Jika pengguna memilih menu Hapus Data, program akan meminta NPM yang ingin dihapus. Jika data tersedia, program akan menghapus data tersebut dan menampilkan pesan "Data berhasil dihapus!".
Jika pengguna memilih menu Tampilkan Semua Data, program akan menampilkan seluruh data mahasiswa yang tersimpan dalam Hash Map berupa pasangan NPM dan nama mahasiswa.
Jika pengguna memilih menu Keluar, program akan menampilkan pesan "Program selesai." dan menghentikan proses eksekusi.
